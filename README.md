# クラウドサービス AWS・Azure・GCP 比較フラッシュカード

40枚のフラッシュカードで AWS / Azure / GCP のサービス対応関係を学習するアプリ。

## 機能

- Compute / Storage / Database / Networking / AI・ML / Messaging / Security / DevOps など9カテゴリ・40枚のカードを収録
- カードをクリックしてフリップ、3クラウドの対応サービスを一覧表示
- 正解 / 不正解を記録し間隔反復アルゴリズムで間違えたカードを優先表示
- カテゴリ別フィルタリングで特定ジャンルを集中学習
- 正解率・カテゴリ別統計・要復習カードを統計画面で確認、進捗を localStorage に保存
